# Iwate.AI Visual System

## Direction

Light, friendly, and illustrated. The page should resemble a polished community flyer converted into a responsive website: generous white space, soft lavender and pink washes, clear black Japanese headings, and LINE green used only where participation is discussed.

## Color

- Strategy: Full palette, with white-tinted surfaces plus purple, pink, blue, and green roles.
- Background: warm off-white, not pure white.
- Primary gradient: purple to magenta to coral for the main CTA and emphasis words.
- LINE green: reserved for LINE badges, participation proof points, and small confirmation accents.
- Neutrals: ink-black tinted slightly toward purple, soft gray-lavender borders.

## Typography

Use Japanese system sans stacks for reliable rendering and fast loading. Headings should be bold, large, and direct, with selected emphasis words using gradient fills only as solid decorative text treatment is banned by the skill, so use solid pink or purple spans instead of gradient text.

## Components

- Rounded pill labels for section context.
- Large pill CTA with LINE icon treatment and arrow.
- Soft bordered panels for comparable content such as benefits, steps, FAQs, and meetup facts.
- Hand-drawn doodle motifs, small sparkles, and extracted illustration crops from the provided reference image.
- Sticky mobile CTA for conversion.

## Motion

Use restrained scroll reveal and hover elevation. Motion should feel welcoming and lightweight, never flashy or blocking. Respect reduced motion.
